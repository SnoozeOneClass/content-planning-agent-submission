# 内容任务规划 Agent 工具费用与耗时规则

状态：已确认当前版本的工具费用与耗时表。

本规则用于内容任务规划 Agent 的成本估算、执行记账和验收核对。素材仅作为参考资料，不包含可直接替代生成结果的已有脚本。

## 用户输入与数值口径

```json
{
  "topic": "字幕功能推广",
  "budget": 10,
  "time_budget": 30
}
```

- `topic`：内容活动主题。
- `budget`：允许消耗的模拟费用总额。
- `time_budget`：从本次任务开始起允许消耗的模拟时间总额，表达相对截止时间。
- 输入、工具配置和输出均使用纯数字，不附加单位后缀；所有时间计算使用同一套模拟时间尺度。
- 工具按顺序执行，耗时累加。

## 已确认的工具费用与耗时表

| 工具 | 单次费用 cost | 单次耗时 duration | 计价范围 |
| --- | --- | --- | --- |
| 素材检索 | `2` | `5` | 按次固定，返回的候选素材数量不影响本次费用和耗时 |
| 脚本生成 | `2 + 2 * n` | `10 + 5 * n` | 每次生成一条脚本，按本次实际处理的素材数量计算 |
| 成本估算 | `0` | `1` | 每次估算均计入耗时 |
| 方案保存 | `0` | `2` | 每次执行保存均计入耗时 |

## 素材数量 n 的定义

- `n` 为本次传入脚本生成工具、实际参与处理的素材 ID 去重后的数量，至少为 `1`。
- 检索得到但未选入本次生成输入的候选素材，不计入 `n`。
- 传入四份素材、最终脚本只引用两份，仍按四份处理量计费。
- 多条脚本分别生成、分别计费。同一份素材参与两次生成，分别计入两次调用。
- 精简素材时仍须保留足够支持主题及脚本内容的依据。

| 本次素材数量 n | 本次生成费用 | 本次生成耗时 |
| --- | --- | --- |
| `1` | `4` | `15` |
| `2` | `6` | `20` |
| `3` | `8` | `25` |
| `4` | `10` | `30` |

## 累计记账与可行性判断

```text
累计已用费用 = 已执行工具调用的费用之和
累计已用耗时 = 已执行工具调用的耗时之和

剩余预算 = budget - 累计已用费用
剩余时间 = time_budget - 累计已用耗时

预计总费用 = 累计已用费用 + 剩余步骤预计费用
预计总耗时 = 累计已用耗时 + 剩余步骤预计耗时
```

候选计划需同时满足：

```text
剩余步骤预计费用 <= 剩余预算
剩余步骤预计耗时 <= 剩余时间
```

计入当前成本估算调用的耗时后，再计算返回的剩余时间和预计完成耗时，避免漏算估算本身。剩余计划还须包含尚未执行的方案保存等必要步骤。

候选计划的估算金额不会直接扣费；仅实际执行过的调用进入累计消耗。重新规划不清零已用费用与耗时，复用成功步骤的结果也不会退回原有消耗。每次真正执行的新尝试单独记账。

执行前被参数、依赖或额度校验拦截的动作不计消耗；工具一旦启动，即使返回失败，也计入该次费用与耗时。成本估算和方案保存失败时同样计耗时。重复请求直接返回已有结果，不新增消耗；显式续跑沿用原有账本。

## 计算核对

检索一次、估算两次、使用两份素材生成一条脚本、保存一次时：

```text
费用 = 2 + 0 + 0 + (2 + 2 * 2) + 0 = 8
耗时 = 5 + 1 + 1 + (10 + 5 * 2) + 2 = 29
```

该执行组合满足 `budget = 10` 和 `time_budget = 30`。
