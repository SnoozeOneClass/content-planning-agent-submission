# AI 辅助使用记录

## AI 承担的工作

AI 助手参与需求拆解、数据与工具接口设计、Python 实现、测试用例、运行材料生成、文档整理与问题修复。代码和当前文档主要由 AI 助手编写，不能将其描述为候选人独立手写。

## 候选人的判断与修改

候选人通过对话确定选题为内容任务规划 Agent，并对设计作出以下明确修改：

- 以题目验收点为边界，取消素材重复度分析及其他生产级扩展。
- 素材仅包含参考资料，取消直接复用已有脚本的设想。
- 不计算真实模型账单，统一使用题目内的模拟费用和耗时。
- 检索按次固定；生成按实际使用素材数量计价；估算和保存免费但计耗时。
- 用户输入剩余时间额度，不要求填写单位；采用 `time_budget` 表达相对截止时间。
- 素材字段精简为 `material_id`、`topic`、`content`；相关度由检索动态返回。
- 指定 DeepSeek 接入，并决定本地完成后再统一提交 GitHub。
- 在本地配置 API Key，使真实模型验收能够执行；密钥未进入仓库。

这些是已发生的需求和方案修改。当前未声称候选人另外手工改过代码或亲自完成过尚未执行的验证。

## 验证方式

通过可执行测试检查预算/时间、失败记账、依赖关系、防重复、状态恢复和模型接口协议；通过 `src.evaluate` 实际运行场景，输出 JSON 和 Trace。离线与真实模型分别标记，固定 Mock 动作不作为真实决策证据。

真实 DeepSeek 验收已完整执行两轮。AI 助手在首轮输出中发现缺少素材依据的体验描述，修改生成提示词后重跑，并阅读最终脚本核对引用。首轮相关输出、改进说明及最终结果均保留在 `examples/`。最终真实模型用例 12/12 通过程序化断言，未将这一数字扩大为所有生成事实的自动正确率。

参考过题面给出的交付示例仓库、CrewAI 营销示例、LangGraph 计划执行示例，以及官方工具调用文档。实现没有直接套用示例中的固定日志；业务运行器与真实模型适配层在本仓库编写。

候选人提交前应阅读并亲自复现 README 命令，确认能够解释费用规则、动态决策边界和失败续跑。后续发生的人工代码修改及实测结果，应继续如实补充到本页。
